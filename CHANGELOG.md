# Changelog

## 1.1.0 - 2026-08-28

- Default to the macOS system proxy instead of a hard-coded local port.
- Add installer options for arbitrary HTTP, HTTPS, SOCKS4, and SOCKS5 proxies.
- Add `chrome-gemini configure` for safe post-install proxy and region changes.
- Document the fully local integration of the upstream enabler behavior.
- Add automated checks that runtime files perform no remote download or
  execution.

## 1.0.0 - 2026-08-28

- Initial macOS CLI, Dock launcher, diagnostics, structured Local State repair,
  installer, uninstaller, bilingual documentation, and tests.
